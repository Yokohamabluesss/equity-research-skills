# Valuation Brief（估值速读）

把一份已完成的估值（通常是 company-valuation skill 产出的 `{TICKER}_Valuation_Dashboard.xlsx`）浓缩成用户自己的投资笔记格式：**指引 / 假设 / 结论**三段，短、准、口径清楚。

## 约定（固定不变）

- **语言**：用用户提问的语言；覆盖已有速读时沿用原文件语言。标题行和三段名是固定字符串：中文 `指引` / `假设` / `结论`，英文 `Guidance` / `Assumptions` / `Conclusion`。
- **文件名**：中文 `{TICKER}_估值速读.md`，英文 `{TICKER}_Valuation_Brief.md`；任一已存在就更新那一份。
- **自检**：`python scripts/check_brief.py 速读.md`（检查标题、三段顺序、结论四条是否齐全且顺序正确、买卖类措辞），修掉所有 FAIL。

## 输入

按优先级读取（`{RESEARCH_ROOT}/{TICKER}/`）：

1. `{TICKER}_Valuation_Dashboard.xlsx`：Conclusion、Assumptions、Revenue & Margin Build、PE & PEG、FCFF Valuation、Reverse DCF & Comps、Consensus Check 各页
2. `{TICKER}_Earnings.md`：核对指引原话
3. `{TICKER}_Financials_*Dashboard.xlsx`：历史毛利率、费用率序列（用于综合判断）
4. 若没有估值表，先提示用户运行 company-valuation，不要凭空编数字

读 xlsx 时用 openpyxl `data_only=True` 取计算值；若公式单元格没有缓存值，先用 LibreOffice 重算（`python scripts/xlsx_check.py 文件` 即可），或用 Python 按同一套公式复算。

## 输出

- 文件：`{RESEARCH_ROOT}/{TICKER}/{TICKER}_估值速读.md`（英文为 `_Valuation_Brief.md`），已存在则覆盖
- 同时在 chat 里贴出全文（代码块），方便用户直接复制
- 用 Tab 缩进的大纲格式，与下方模板逐字段对齐

## 固定模板

```
{TICKER} 估值速读（股价 ${价格}，{取价日期}）

指引
	{下一季指引：营收区间、毛利率区间、OpEx 区间、EPS 区间}
	{管理层长期目标 / 里程碑：如「FY27 末首个 >$3B 季度」、长期 GM / OpEx 模型}
假设
	{FY cur 剩余季度营收路径及来源，例：每季 +9.25%（由 >$3B 目标反解）}；{FY+1 营收路径及来源}
	{毛利率路径：每季步长、何时触及长期目标}；{OpEx% 路径}
结论
	① 营收路径来源与保守度
	② 利润率路径（含综合判断）
	③ 估值：PE 与增速分列 → PEG → FCFF 反推
	④ 与一致预期的差异
```

## 结论四条的写法（硬规则）

### ① 营收路径来源与保守度

- 写清 FY cur 营收主要基于什么：🟢 指引锁定 / 🟡 管理层目标反解 / 🔴 自建假设，并给出**指引覆盖率**（估值表 Conclusion 页 ②）
- 判断「偏保守 / 中性 / 偏乐观」时，**理由必须和公司的约束类型对上**：
  - **供给受限型**（产能决定收入，如 InP 产能翻倍）：用「产能扩张进度、订单是否订满、订单可见度延伸到哪」论证，**不要只用「行业需求好」**
  - **需求驱动型**：才用行业需求、订单增速、库存周期论证
- FY+1 若为自建假设，必须单独点出「可见度较低」

### ② 利润率路径（要综合判断，不机械贴标签）

- 区分**全年口径**与**单季退出口径**：例「FY27 营业利润率 20.4% → 24.0%（Q4 单季 25%）」，不能把单季数写成全年
- 拆成「毛利率改善」与「费用率摊薄」两个来源，各自说依据
- 费用率下降：区分「有管理层原话支撑的方向」与「自建的斜率」
- **长期目标的达成时点要综合判断**：公司若只给了目标值（如 GM >42%）而没给时间，先写明「未给达成时点，模型假设在某季达成」，再给出判断，判断必须同时用到下面三类证据：
  1. **所需斜率 vs 历史斜率**：从**最新实际值**（不是指引值）到目标需要的每季升幅，对比最近 4 季实际升幅均值
  2. **驱动因素是否在路上**：产能 / 工艺升级（如 6 寸晶圆占比）、高毛利新品放量时点、定价环境
  3. **行业需求与供需状态**：供不应求时定价有支撑，利于毛利率
  - 结论落在「比较合理 / 偏乐观 / 偏保守」之一，并保留关键数字
  - 「当前」必须指最新实际值，指引值另行标注（例「从 FY26 Q4 的 40.2%（Q1 指引中值 40.5%）出发」）

### ③ 估值（顺序固定，不可调换）

1. **先分开列两年**，每年一行，P/E 与 EPS 增速同时给出：
   - `FY{cur} PE {x}x，EPS 增速 {g}%`（若增速含一次性成分，如利润率从周期低点修复、低基数，在后面括注 ⚠️）
   - `FY{cur+1} PE {x}x，EPS 增速 {g}%`
2. **再说 PEG**：主口径用 Lynch 多年 CAGR 版（FY cur P/E ÷ 两到三年 EPS CAGR），并给出数值；若 FY cur 单年 PEG 因一次性成分失真，一句话说明为什么不用它；有可比公司数据时补一句同口径对比（例「与 LITE 的 PEG 相当」）
3. **最后写 FCFF 反推**：
   - 仅当估值表判断 FCFF 适用度为「中」或「高」时写；适用度「低」时写「FCFF 不适用：{一句话理由}」
   - 写法：「现价需要 FY{x} 之后再以 {g_high} 增长约 {N} 年（成熟利润率 {m}%）」，并与估值表 Base 假设、管理层长期模型对比，判断市场隐含条件更激进还是更保守
- **不写「便宜 / 贵 / 值得买」**。如果用户自己的草稿里有这类判断，改写为条件句：「近两年 PE 不贵；若要接受现价，需要相信 {条件}」

### ④ 与一致预期的差异

- 给出 FY cur 与 FY+1 的 EPS 差异百分比
- 一句话说分歧来源（营收 / 利润率 / 转换率与股本），偏离超过 ±10% 时标 ⚠️

## 校对用户草稿时（用户先给了自己的版本）

保留用户的结构、措辞风格与判断，只改以下几类问题，并在 chat 里逐条说明改了什么、为什么：

1. 论证理由与约束类型对不上（供给受限却只用需求论证）
2. 单季数写成全年，或全年写成单季；把指引值写成「当前」实际值
3. 把模型假设写成公司指引（尤其是长期目标的达成时点）——但用户给出的综合判断应保留，只补上支撑数字
4. 单年增速含一次性成分却直接拿来判断估值
5. 「便宜 / 贵」类结论缺少反推条件
6. 空着的段落（如「假设」为空）用估值表补齐

## 示例（COHR，2026-10）

```
COHR 估值速读（股价 $312.62，2026-10-09 收盘）

指引
	FY27 Q1：营收 $2.2–2.4B、GM 39.5–41.5%、OpEx $400–420M、EPS $1.85–2.05
	FY27 末首个 >$3B 季度；长期 GM >42%、OpEx 18%
假设
	FY27 Q2–Q4 营收每季 +9.25%（由 >$3B 目标反解）；FY28 每季 +8%（自建）
	GM 每季 +50bps，FY27 Q4 到 42%；OpEx% 17.8% → 17.0%
结论
	FY27 营收主要基于管理层目标反解（指引覆盖率仅 9%）；公司处于供给受限，产能翻倍已提前一季完成、FY27 订满、订单进入 CY2028，目标偏保守。FY28 为自建假设，可见度较低
	FY27 营业利润率由 20.4% 升至 24.0%（Q4 单季 25%），毛利率改善与营收摊薄费用共同推动。费用率下降方向管理层明确表态；42% 毛利率是管理层长期目标，未给达成时点，模型假设 FY27 Q4 达成：从 FY26 Q4 的 40.2%（Q1 指引中值 40.5%）出发，需每季约 +45bps，低于 FY26 四季均值 +53bps，叠加 6 寸 InP 占比提升与 1.6T / OCS / CPO 等高毛利产品即将放量，FY27 达成比较合理
	FY27 PE 32.8x，EPS 增速 70%（⚠️ 含毛利率从周期低点修复的一次性成分）
	FY28 PE 21.5x，EPS 增速 53%
	PEG（FY26→FY28 两年 CAGR 61%）约 0.54，与 LITE 相当（同口径 0.68 vs 0.66）；FY27 单年 PEG 0.47 因一次性成分偏低，不作主口径
	FCFF 反推：现价需要 FY28 后再以 +25% 增长约 5 年（成熟 GAAP EBIT 率 24%），按管理层长期模型的约 21% 则需约 6 年；估值表 Base 只假设 3 年，市场隐含条件比管理层模型更乐观
	与一致预期基本一致（FY27 EPS +1.0%，FY28 +3.7%），分歧在利润率扩张幅度，不在增速
```

## 原则

- **股价 = 调用 skill 当天的最新价。** 估值表里的股价较旧，或股价格与备注不一致时，重新抓最新价，用表内 EPS 重算倍数，标题行写这个日期
- 只用估值表、电话会与财务仪表盘里的数字，不新增预测
- 每个数字的口径（全年 / 单季、实际 / 指引、Non-GAAP / GAAP、FY 截止月）要清楚
- 不给买卖建议、不给目标价；FCFF 每股价值不是目标价
