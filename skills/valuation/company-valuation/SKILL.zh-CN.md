# Company Valuation（公司估值）

对已经研究过 / 已经跟踪过财报的上市公司做估值判断，输出一份**跨公司格式统一**的 xlsx 估值仪表盘 + 一段简短解读。核心是让用户打开表格 30 秒内在**结论页**看到四件事：

1. 这个模型推出来的增长路径，**哪些是公司指引锁的、哪些是我假设的**；
2. 关键指引与关键假设各是什么；
3. 和卖方一致预期差在哪、差在哪个变量；
4. **这家公司到底该用 PE、FCFF，还是 SoTP**。

再往后翻才是 PE / PEG、FCFF、反推与可比公司交叉检查的明细。

## 约定（固定不变）

- **语言**：sheet 名一律用下文固定的英文名；单元格文字（标签、依据、备注）用用户提问的语言；更新已有估值表时沿用原表语言。
- **模板由脚本保证**：用 `scripts/val_style.py` 建表（sheet 清单、配色、字体、数字格式、页面布局），不要每次手打色号和格式。
- **交付前检查**：`python scripts/check_valuation_xlsx.py {TICKER}_Valuation_Dashboard.xlsx`——用 LibreOffice 重算，扫描公式错误和以 `=` 开头的文字，并检查模板（sheet 名与顺序、冻结窗格、方法结论行、依据列、终值占比）。所有 FAIL 必须修掉。
- **来自其他 skill 的输入**：`{TICKER}_Earnings.md`、`{TICKER}_Financials_*Dashboard.xlsx`、`{TICKER}_速读.md` 或 `{TICKER}_Digest.md`、`{TICKER}_*_首次研究.md` 或 `{TICKER}_*_Initial_Coverage.md`。

## 核心原则

### 1. ⭐ EPS 预测必须自下而上逐季建模，一致预期只作交叉验证

**这是本 skill 最重要的一条，也是最容易偷懒的地方。**

❌ **禁止**：直接把卖方一致预期的全年 EPS 填进模型当作 Base 情境。
✅ **必须**：从**电话会指引 + 财务趋势 + 订单与可见度 + 行业需求 + 产品放量节奏**五类证据推导出**每个季度**的营收环比、毛利率、费用率，再逐层算到 EPS。

理由：一致预期是"别人的模型的平均值"，它既不解释自己的假设，也会滞后于最新的电话会信息；照抄它等于放弃了做这份表的全部意义。用户要的是"**你凭什么这么预测**"，不是"**别人怎么预测**"。

一致预期的正确用法有两个，都必须做：
- **反解它隐含的逐季路径**（见原则 3），与自建路径逐季并排对照
- **作为自建结果的合理性检验**：若自建全年 EPS 与一致预期偏离超过 ±10%，必须在 Notes 与结论页里解释偏离来自哪个变量（营收节奏？毛利率？费用？股本？）

### 2. ⭐ 每一个假设都必须写清楚"为什么"

Assumptions 页**强制三列**：`假设项 | 值 | 依据与推导过程`。

第三列不接受"假设""预计""参考历史"这类空话，必须落到具体证据，至少属于以下之一：
- **电话会原文**（引管理层的话，中英对照）
- **公司指引数字**（区间与中值，并说明用了区间的哪一端）
- **可验证的历史序列**（例："过去 4 季毛利率单季升幅 +60/+30/+57/+66bps，均值 +53bps，故取 +50bps"）
- **订单/产能/产品节奏事实**
- **管理层的长期目标反解**

**若某个假设确实无据可依，就写"无直接依据，取 X（保守/中性处理）"——诚实标注，不要包装。**

### 3. ⭐ 必须反解一致预期的隐含逐季环比

一致预期通常只给全年营收和全年 EPS。必须把它拆成逐季：
- 已指引季度用公司指引锁定（这部分卖方也必然照搬）
- 剩余季度按**等比环比**反解：设剩余 N 个季度环比增速恒为 g，解方程使全年合计等于一致预期
- 把反解出的 g 与自建路径的 g 并排列出

这一步的价值：能立刻看出"卖方到底在假设什么"。

### 4. ⭐ 三种估值方法，先选后算（V3 新增）

本 skill 支持 **PE / PEG**、**多阶段 FCFF（含反推）**、**SoTP** 三条路径。**开工前必须先判断这家公司适合哪条**，并把结论写在结论页第一行。判断框架见下面的「估值方法选择框架」章节。

默认动作：
- **PE 与 FCFF 一起做**（PE 做近端锚，FCFF 做远端与反推），并在结论页给出"哪个更可信"的一句话判断；
- **只有当判断为 SoTP 更合适时**，才把 FCFF 页改造成 SoTP 页（见「SoTP 变体」章节）。

### 5. ⭐ FCFF 不追求单点精确，追求「情景 + 反推」

FCFF 最没用的用法是算出一个精确到分的每股价值然后当目标价。本 skill 的 FCFF 有且只有三个任务：

1. **三情景**：只变**高速增长持续年数 N1** 与**成熟期 EBIT margin**（外加永续增速），看每股价值的区间有多宽——宽度本身就是信息；
2. **反推**：固定 WACC 与永续增速，反解**当前股价隐含的 (N1, 成熟期利润率) 组合**，然后判断这些条件合不合理；
3. **交叉检查**：用未来 1–2 年 PE 与可比公司比，看增长与盈利质量能否解释本公司的溢价/折价。

⚠️ **FCFF 算出的每股价值不是目标价**，输出时必须表述为"在 X 情景假设下模型给出的每股价值为 $Y"，并紧跟一句"这不是目标价"。

### 6. Non-GAAP 与 GAAP 分别算一遍

两个口径对盈利质量的看法差别显著——只看一个会误判。

**GAAP 不单独建模**，用 `GAAP EPS = Non-GAAP EPS − delta/股` 反推。delta 的取值必须给依据：
- 拆解 delta 构成（收购无形资产摊销 / SBC / 重组 / 减值 / 出售收益 / 税收调整）
- 区分**刚性部分**（摊销）与**弹性部分**（SBC）
- 说明 delta 未来是收窄还是走阔，并给出理由

⚠️ **FCFF 一律用 GAAP 口径的 EBIT 起算**，不能用 Non-GAAP EBIT——SBC 是真实的股东成本，把它加回去会系统性高估自由现金流。若公司 SBC 占营收比重较高，必须在 Notes 里点明这一处理。

### 7. P/E 的时间对齐必须严格

分子（股价）代表"现在"，分母（EPS）必须选一个明确的时间口径。**强制三种时间口径**：
- **FY(current)** — 当前财年
- **NTM (Next Twelve Months)** — 从"今天"往后滚动 12 个月，权重按实际月数计算并写明
- **FY(current+1)** — 下一个完整财年

### 8. PEG 必须时间对齐

PEG = P/E ÷ G。**如果 P/E 分母用 FY(t) EPS，G 必须是 FY(t) 相关的增速**：

| PEG 版本 | 分子 P/E | 分母 G | 用途 |
|---|---|---|---|
| **PEG (FY cur)** | FY(cur) P/E | FY(cur) YoY EPS growth | 📌 **投行 standard**，主口径 |
| **PEG (Peter Lynch)** | FY(cur) P/E | 2–3 年 forward EPS CAGR | 📌 Lynch 原版，平滑单年扰动 |
| **PEG (NTM)** | NTM P/E | 同上多年 CAGR | 滚动口径 |
| **PEG (保守)** | FY(cur) P/E | 卖方多年增速预测 | 保守边界 |

**禁止输出**：**FY(cur) P/E 配 FY(cur+1) YoY G** —— 时间不对齐，是最经典的估值错误。

⚠️ 另一个同样常见的错配：**EPS 口径的 P/E 配营收增速**。P/E 的分母是 EPS，G 就必须是 EPS 增速，不能拿营收增速去除。若要用营收增速，对应的倍数是 EV/Sales 而不是 P/E。

如果 FY(cur) 存在 reset 效应（低基数、并购一次性、上一年基数为负、利润率从周期低点修复），该版本 PEG 会失真，**必须在表里用 ⚠️ 显式警示**，并在结论页推荐改用 Lynch 多年 CAGR 口径。

### 9. 不给买卖建议 / 不给目标价 / 不判断"贵便宜"

只客观呈现倍数、每股价值区间、隐含条件，以及与历史区间和同业的对比。措辞用"当前 NTM PE 为 X 倍，同业为 Y 倍""要撑住现价需要高速增长 N 年且成熟利润率达 M%"，而不是"贵""便宜""值得买"。

## ⭐ 估值方法选择框架（V3 新增）

### 先过三道否决题

| # | 问题 | 若"否" |
|---|---|---|
| 1 | 预测期内**持续盈利**，且 GAAP / Non-GAAP 口径差额小而可预测？ | **PE 不可用或严重失真** |
| 2 | 自由现金流**方向可预测**（资本开支节奏清楚、不处于极端扩张或收缩期）？ | **FCFF 可信度低** |
| 3 | 是**单一主业**，各板块估值逻辑相近，且无大额非经营资产？ | **应改用 SoTP** |

### 再看正面适配条件

**PE / PEG 优先**，当：
- 单一主业、盈利为正且口径干净
- 成长可见度来自**订单 / 长约 / 合约金额**（可外部验证）
- 资本开支不主导现金流，或已与收入同步
- 存在清晰的可比公司群（同赛道、同商业模式、同增长档位）

**FCFF 优先**，当：
- 现金流稳定可预测，资本周期已过峰
- **缺乏可比公司**（业务独特、跨赛道、没有像样的同业倍数可参照）
- 利润率处在结构性抬升中段，PE 的分母对假设过度敏感（分母变 10%，P/E 反向变约 11%）
- 终值占 EV 比重可控（<75%）

**两者并用（本 skill 默认）**：PE 做近端锚（1–2 年，可验证），FCFF 做远端与反推（回答"现价隐含了什么"）。两者结论若冲突，冲突本身是最重要的输出。

**SoTP 更合适**，当出现以下任一：
- **多板块估值逻辑差异悬殊**：例如「设备制造（低毛利、周期、份额战）+ 软件订阅（高毛利、经常性）+ 专利授权（近乎纯利润、与出货量脱钩）」并存——集团层面任何单一倍数都会被高毛利板块拉高、被低毛利板块拖累，两头不讨好
- **板块间增速方向相反**（一块下滑、一块高增），集团增速掩盖了结构
- **有大额非经营资产**：净现金占市值比重高、专利池、长期股权投资、地产
- **有大额少数股东权益或合资结构**，母公司口径与合并口径差异大
- **正在分拆 / 出售某个板块**

> 典型例子：一家由「移动网络设备 + 网络基础设施 + 云与网络服务 + 专利授权」四块组成的通信设备商，专利授权业务营收占比不到 10% 但可能贡献三成以上营业利润，且与设备出货周期完全脱钩。用集团 PE 会同时高估设备业务、低估专利业务；用集团 FCFF 则会把两条完全不同的现金流曲线糊成一条。这类公司应当**逐板块选择方法**（设备用 EV/Sales 或 EV/EBITDA、软件用 EV/Sales、专利授权用 DCF 或永续现金流），加总后再调整净现金与少数股东权益。

### 输出要求

**结论页第一行必须是一句话方法结论**，格式固定：

> **方法结论**：本公司当前更适合用 **{PE / FCFF / PE+FCFF 并用 / SoTP}**，因为 {一句话理由}；{被排除的方法} 不适用，因为 {一句话理由}。

### Step 0：确定 scope（10 秒）

- **公司**：股票代码 / 交易所
- **财年位置**：最新已披露季度是哪一季，当前在跑的是哪一季
- **股价**：**必须** web search 抓调用 skill 当天的最新价（复用已有估值表时也要刷新），在股价格旁记录日期和时点（收盘 / 盘中 / 盘后）。结论页的股价、倍数和 FCFF 结果一律用公式引用单元格，不手填数字，股价一改全表联动
- **⭐ 方法预判**：过一遍上面的三道否决题，先在心里定下 PE / FCFF / SoTP，后续 Step 才有的放矢

**如果用户在前序对话已经在讨论某家公司**（刚做完 earnings call reader、刚更新完 dashboard），直接默认那家公司，**不要反问**。

ls {RESEARCH_ROOT}/{TICKER}/{TICKER}_*_首次研究.md 2>/dev/null                 # 定性背景

从这些文件里提取建模所需的**五类证据**：

| 证据类别 | 从哪里拿 | 用来定什么 |
|---|---|---|
| **① 公司指引** | Earnings.md 的 Guidance 板块 | 下一季营收 / 毛利率 / 费用 / 税率 / EPS 的锚点 |
| **② 财务趋势** | Financials Dashboard | 历史 QoQ/YoY 序列、毛利率升幅序列、费用率趋势、转换率 |
| **③ 订单与可见度** | Earnings.md 的 Order Book 板块 | 营收增速能否维持、可见度延伸到哪个财年 |
| **④ 行业需求 / 产能** | Earnings.md 的 Demand / Capacity 板块 | 需求受限还是供给受限；产能爬坡时点 |
| **⑤ 产品放量节奏** | Earnings.md 的 Product Summary Table | 新产品首笔收入时点与爬坡曲线 |

### Step 2：⭐ 自下而上逐季建模

按以下**固定顺序**逐层推导，每一层都要留下依据：

#### 2.1 营收路径（逐季 QoQ）
- **已指引的季度**：直接用指引中值（Base）、上限（Upside）、下限（Downside）
- **未指引的季度**：QoQ 增速必须从下面至少一条推出：
  a. **管理层长期目标反解** ⭐ 优先级最高（run-rate 目标、单季营收里程碑、产能倍数）
  b. **产能/供给节奏**：产能翻倍时点、瓶颈解除时点、"完整财务效果在某季体现"这类表述
  c. **订单可见度**：backlog 覆盖到哪、合约金额、是否已订满
  d. **产品放量节奏**：哪个季度有新产品首笔收入进来
  e. **历史季节性**：仅在需求驱动型公司使用；**供给受限型公司季节性权重应显著调低**
- ⚠️ **产能释放是阶跃还是线性，是最容易被忽略的分歧点**。若管理层明说"完整财务效果在某季体现"，该季环比就应显著高于相邻季，不能拉平成等比增长

#### 2.2 毛利率路径
- 起点：下一季指引区间
- ⭐ **优先假设「增量毛利率」而不是直接假设毛利率数值**：`GP(t) = GP(t−1) + 增量GM × ΔRev`。增量毛利率的依据可来自管理层披露的实测落地率，或由「当前点」与「长期模型点」两点反解
- **必须对照公司自己的长期毛利率目标**，说明路径何时触及该目标

#### 2.3 营业费用路径
- 起点：下一季指引中值 ÷ 营收中值
- 后续：参考公司是否有 **OpEx 目标模型**，以及管理层对经营杠杆的表述
- 注意分项趋势可能相反（SG&A 在降、R&D 在主动加码）

#### 2.4 营业利润 → 净利的转换率
- **列出最近 4 季的实际转换率序列**，看趋势
- **用下一季的 EPS 指引反校准**——若公司不给 EPS 指引，改用**毛利或营业利润与一致预期交叉验证**
- 三情境共用同一条转换率路径

#### 2.5 摊薄股本
- 区分**一次性稀释**与**经常性稀释**（股权激励通常 1–2%/年）
- 若管理层明确表示扩产不摊薄，引原文

#### 2.6 得出 EPS
`EPS = (营收 × 毛利率 − 营业费用) × 转换率 ÷ 摊薄股本`，全部用 Excel 公式串起来。

### Step 3：⭐ 反解一致预期并对照

1. 抓一致预期的**全年营收**与**全年 EPS**（记录来源、家数、更新日期、口径是 GAAP 还是 Non-GAAP）
2. 用等比环比反解剩余季度的隐含 QoQ
3. **逐季并排列出自建 vs 一致预期**，并**逐变量归因**差异（营收贡献几个点、毛利率贡献几个点、费用/税率/股本各贡献几个点）
4. 用一句话点出**分歧的本质**（是"增速高低"之争，还是"节奏形态"之争？）

### Step 6：⭐ 多阶段 FCFF 三情景（V3 新增）

#### 6.1 WACC 推导（必须留下每个输入的依据）
```
Ke = Rf + β × ERP
Kd(税后) = Kd(税前) × (1 − 税率)
WACC = Ke × E/(D+E) + Kd(税后) × D/(D+E)
```
- Rf：取当地 10 年期国债收益率，注明取数日
- ERP：注明来源（Damodaran / 券商口径）
- β：注明取数来源与回归区间；若公司刚经历商业模式转型，说明历史 β 是否仍适用
- 权重用**市值**与**账面债务**，不用账面权益

#### 6.2 三阶段结构
| 阶段 | 年数 | 营收增速 | EBIT margin |
|---|---|---|---|
| 高速期 | **N1（情景变量）** | g1（由自建模型延伸） | 由当前水平线性爬升至 **m_mature（情景变量）** |
| 过渡期 | N2（固定，通常 3–5 年） | 从 g1 线性衰减到 g_term | 稳定在 m_mature |
| 永续期 | ∞ | **g_term ≤ 名义 GDP（通常 2.0–3.0%）** | m_mature |

⭐ **三情景只变三个变量：N1、m_mature、g_term。** 不要机械地把营收 ±10%——那样等于没做情景分析。

#### 6.3 逐年 FCFF
```
FCFF = EBIT × (1 − 税率) + D&A − CapEx − ΔNWC
```
- **EBIT 用 GAAP 口径**（见原则 6）
- D&A 与 CapEx 必须给出与营收的比率路径，并说明何时收敛（重资本扩张期结束后 CapEx/营收应回落至接近 D&A/营收）
- ΔNWC：用历史「营运资本 / 营收」比率外推；**若公司有大额客户预付款，要单独说明它是 NWC 的负项、会在交付期反向流出**

#### 6.4 估值汇总（必带项）
```
EV = Σ PV(明确期 FCFF) + PV(终值)
终值 = FCFF(终年) × (1+g_term) / (WACC − g_term)
股权价值 = EV + 净现金 − 少数股东权益
每股价值 = 股权价值 ÷ 摊薄股本
```
- ⭐ **必须报告「终值占 EV 的比重」**：
  - <60%：正常
  - 60–75%：可接受，但要提示
  - **>75%：⚠️ 估值主要由终值假设驱动，FCFF 结论的可信度下降**
  - **>85%：🔻 FCFF 不宜作为主要方法，退回 PE 或 SoTP，并在结论页说明**

#### 6.5 敏感性矩阵（必带）
以 **N1（高速增长持续年数）× m_mature（成熟期 EBIT margin）** 做二维矩阵，输出每股价值。这两个变量是用户最关心的，其余（WACC、g_term）固定并在表头注明。

### Step 7：⭐ 反推 + 可比公司交叉检查（V3 新增）

#### 7.1 反推当前股价的隐含条件（Reverse DCF）
固定 WACC 与 g_term，令模型输出的每股价值等于当前股价，反解所需的 **(N1, m_mature) 组合**，输出一张组合表：

| 若成熟期 EBIT margin 为 | 则需要高速增长持续 |
|---|---|
| m_mature − 5pp | N 年 |
| m_mature（管理层目标） | N 年 |
| m_mature + 5pp | N 年 |

然后回答两个问题（这是全表最有说服力的一段，因为它不需要预测，只需要判断条件合不合理）：
1. **市场隐含的条件 vs 管理层自己的长期模型，谁更激进？**
2. **这些条件在产业上可达吗？**（对照产能规划、合约覆盖年限、竞争格局、产品生命周期）

#### 7.2 未来 1–2 年 PE 与可比公司交叉检查
选 **3–6 家可比公司**（同赛道 / 同商业模式 / 同增长档位），列：

| 公司 | NTM P/E | FY+1 P/E | FY+1 EPS 增速 | 毛利率或净利率（盈利质量） | 隐含 PEG |
|---|---|---|---|---|---|

判断的落点**不是"谁的 PE 低谁便宜"**，而是**匹配性**：本公司相对同业的溢价/折价，能否被**增长速度**与**盈利质量**两项解释？若不能解释，缺口来自什么（可见度更高？周期位置不同？治理/地缘折价？）。

### ② 增长路径基于什么：指引 vs 假设（⭐ 本页最核心的区块）

逐个预测期（按季或按年）标注来源三分法，**并给出「指引覆盖率」**：

| 期间 | 营收 | 来源分类 | 具体依据 |
|---|---|---|---|
| 2026Q3 | $520M | 🟢 **指引锁定** | 公司正式指引中值 |
| 2026Q4 | $570M | 🟡 **管理层目标反解** | 由"某产品 $1B run rate"目标反解 |
| 2027Q1–Q4 | … | 🟡 **管理层目标反解** / 🔴 **自建假设** | … |

**指引覆盖率** = 预测期内被公司正式指引直接锁定的营收 ÷ 预测期总营收。
必须用一句话点评这个比例，例如："预测期总营收中仅 10.8% 被公司指引直接锁定，其余 89.2% 来自管理层目标反解与自建假设——**这意味着模型的可靠性主要取决于管理层长期目标的兑现度，而非短期指引的准确性**。"

三档定义：
- 🟢 **指引锁定**：公司正式给出的季度/年度指引数字
- 🟡 **管理层目标反解**：从管理层公开的 run-rate 目标、单季里程碑、产能倍数、合约金额反解而来（**有依据但未被指引背书**）
- 🔴 **自建假设**：无直接管理层依据，由历史序列、行业判断或保守处理给出

### ③ 关键指引汇总

把建模用到的**全部公司指引**集中列一遍：指标 / 指引值 / 时间范围 / 原文引用。让读者不必翻 Assumptions 页就能看到锚点。

### ④ 关键假设汇总

只列**对结果最敏感的 5–8 条**（不是全部），每条给：假设项 / 取值 / 一句话依据 / **敏感度**（该假设变动 ±X 时 EPS 或每股价值变动 ±Y%）。敏感度这一列是新增的硬要求——它告诉读者该盯哪几个假设。

### ⑤ 与一致预期的差距点

- 逐年对照：营收 / 毛利 / EPS 的自建 vs 一致预期 vs 差异%
- **逐变量归因**：差异中营收贡献几个点、毛利率贡献几个点、其余贡献几个点
- **一句话点出分歧的本质**：是"增速高低"之争，还是"节奏形态"之争，还是"口径不同"？
- 若某个方向偏离超过 ±10%，必须在此显式标 ⚠️ 并说明理由

## 解读框架（经验参考，非硬规则）

**NTM PE 的经验区间（科技硬件）**：<15x 低估区 / 15–25x 合理区 / 25–40x 溢价区 / >40x 高估区（要有极强的多年可见度）。

**PEG 的经验区间（Lynch 原版口径）**：<0.7 显著低估（罕见）/ 0.7–1.2 合理 / 1.2–1.5 偏贵但可解释 / >2 显著高估。

**FCFF 终值占比**：<60% 正常 / 60–75% 提示 / >75% ⚠️ / >85% 🔻 改用其他方法。

**反推结论的读法**：若现价隐含的条件**比管理层自己的长期目标还激进**，说明市场已经把"超额兑现"计入价格；若**低于管理层目标**，说明市场对目标兑现度打了折扣——两种情况都不构成买卖建议，但决定了"你需要相信什么才能接受现价"。

**以下情境倍数分位不适用，必须显式说明**：
- 周期股在周期底部：分母 EPS 偏低导致 PE 虚高 → 改看 EV/Sales 或 EV/EBITDA
- 亏损公司：EPS 为负，PE 不适用
- 并购当期：一次性 GAAP 费用压低 EPS
- **高增速中的成长股：PEG 会显得极低，但要检验分母增速由哪几个因素构成、能维持几年**——这是最常见的误读来源
- **利润率修复型增长**：EPS 高增速中有一块来自利润率从周期低点回升，属一次性、不可重复，用单年 YoY 做 PEG 分母会系统性低估 PEG
