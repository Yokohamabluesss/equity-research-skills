# Earnings Digest（财报速读：逻辑和叙事 + 财报会议）

把一家公司**已有的 `{TICKER}_Earnings.md`**（由 earnings-call-reader 产出的详细跨季度日志）浓缩成一份**投资视角的精简速读**，固定两大板块：`===逻辑和叙事===` 和 `===财报会议===`。目标是让人 30 秒看完就知道「这家公司凭什么值钱（逻辑）」+「本季电话会最该抓的几件事、以及每一维到底好不好（会议）」。

## 定位与接力关系

- **输入**：一份 `{TICKER}_Earnings.md`（详细日志，含多个季度的 TL;DR / Guidance / 分产品 / Order Book / Customers 等）。若用户直接贴了一段电话会纪要而**没有** md，先提示"建议先跑 earnings-call-reader 生成详细日志，再用本 skill 浓缩"，或在对话里临时按本格式速读。
- **本 skill 只做浓缩 + 判断、不重新分析**：所有事实必须能在输入 md 里找到依据，不外部查证、不臆测（用户后续追问除外）。但**判断是本 skill 的产出之一**——见下面的「判断标记」章节。
- **下一步**：investment-view 以本速读的「逻辑和叙事」作为核心，以财报会议块作为季度判断块的起点。
- **区别于 earnings-call-reader**：那个是"读厚"（把一季读成结构化长笔记）；本 skill 是"读薄 + 定调"（把长笔记压成一页速读，并对每一维给出好/隐忧/转弱的判断）。

## 约定（固定不变）

- **语言**：用用户提问的语言；更新已有速读文件时沿用该文件的语言。标注、分块标记和 tag 都是固定字符串（中英文模板见下），不得改写。英文版固定写法：`===Logic & Narrative===` / `[Core in one line]` `[Main growth driver]` `[New narrative]` / `===Earnings Call===` / `**Financials**` `**Sub-industry**` `**Orders**` `**Customers**` `**Momentum**` / `Other:` / tag `Beat` `In line` `Miss`。
- **季度标签**：`FY{YY} Q{n}`，与电话会日志一致（如 `FY26 Q4`）。
- **自检脚本**：写完后把草稿存成文件跑 `python scripts/check_digest.py draft.md`（或从 stdin 传入），修掉所有 FAIL；WARN 是提醒你再检查一遍。

## Step 0：确定范围（5 秒）

- **公司**：从文件名 `{TICKER}_Earnings.md` 或上下文确定。若刚在讨论某公司，直接默认它，不反问。
- **季度范围**：默认只速读**最新一个季度**的 `===财报会议===`（`===逻辑和叙事===` 永远是跨季度提炼、不分季）。
  - 用户说「对比最近 N 季」「历季演进」→ 多季模式：`===财报会议===` 下并列多个 `---{财季}---` 块，并在每块的「业绩节奏」里重点写与上季的 delta。
- **输出去向**：默认**直接在对话里输出**（用户通常要的就是贴到自己笔记里）。用户说「存文件」再写到 `{同目录}/{TICKER}_速读.md`（中文）或 `{TICKER}_Digest.md`（英文）；任一文件已存在就更新那一份。

## ⭐ 判断标记（emoji 是判断，不是项目符号）

**这是本 skill 最容易被误用的地方。** 六维前面的 emoji **不是 checkbox、不是装饰**，而是你对该维度本季表现的**明确判断**。三选一：

| 标记 | 含义 | 使用条件 |
|---|---|---|
| ✅️ | **这一维本季表现好、方向正面** | 该维度的关键信号绝大多数向好，没有实质性反面证据 |
| ⚠️ | **这一维有实质隐忧或信号混杂** | 好坏并存；或有一条足以改变判断的负面信号（如关键数字停止更新、重要客户消失、口径变模糊） |
| 🔻 | **这一维明确转弱** | 主要信号方向向下，或出现拐点级别的恶化 |

**铁律**：
1. **一份速读里六维全是 ✅️ 是可疑的**——说明你没做判断，只是在贴标签。绝大多数季度至少有一到两维应该是 ⚠️。
2. **标记必须能被该维正文自证**：打 ⚠️ 就必须在正文里写清楚"隐忧是什么"；打 ✅️ 就不能在正文里塞一堆负面信号。
3. **判断只针对"本季这一维的信号质量"，不是对股票的判断**——不写买卖建议、不判断贵便宜。
4. 「其他」栏不打判断标记，用纯编号列表。

## 各维度的填写要点（这决定速读的信噪比）

### 【逻辑和叙事】—— 先定调，再展开

三个方括号标注是**强制项**，必须放在编号条之前：

- **【公司一句话核心】**：回答"它是谁、在哪一层"。好的写法点出它与相邻环节的分工（例："不做模块、不做系统，做的是模块厂与系统厂上游的 PIC"）。**不要写成公司简介**，要写成产业链定位。
- **【增长主驱动】**：回答"这一轮的钱从哪来"。必须落到一条可追溯的需求曲线上（某个终端市场的渗透、某代产品的换代、某类客户的资本开支）。如果有伴生的第二条同步曲线（如主产品 + 配套器件按 1:1 增长），一并点出。
- **【新叙事】**：回答"市场可能还没充分定价的是什么"。通常是本季或近几季才浮现的第二曲线、身份转变（如从"卖零件"到"卖集成能力"）、新的商业模式。**若确实没有，就诚实写"本季无新增"**——连续两季无新叙事本身就是一个信号。

下面的编号条仍然只放**跨季度稳定**的护城河与长期逻辑，不放本季新闻（本季新闻属于「业绩节奏」）。

### 【财务】—— ⭐ 抓"导数"与"程度"，不是抓"数字"

**这一栏的产出是判断，不是数据搬运。** 数字只保留少数几个锚点；其余用**趋势方向 + S 曲线位置 + 二阶导 + 程度副词**表达。

**必须回答的四个问题：**

1. **营收在加速还是减速？**是"beat + raise"的完整组合，还是只 beat 不 raise / 只 raise 不 beat？
2. **"利润率 %"这条 S 曲线在哪一段？**——最陡段 / 过了最陡点减速上行 / 见平台。
3. **"利润绝对额 $"这条 S 曲线在哪一段？**——⭐ **必须与利润率分开讲，二者拐点通常不同步**。
4. **天花板（asymptote）有没有被移动？**管理层上修/下修长期利润率目标，比当季利润率本身更重要。

**内部算法（自己算，不一定全写出来）：**
- 定位**利润率 %** 的位置：看**利润率 QoQ 增幅序列**在放大还是收窄。例：+650→+700→+440→+340 → 峰值在第 2 点、之后收窄 → 判断为"过了最陡点、减速上行"。
- 定位**利润绝对额 $** 的位置：看**经营利润 / 净利的 QoQ 增量序列**在放大还是收窄。只要营收还在猛爬，即便利润率减速，绝对利润仍可继续加速。
- **两条曲线的关系**：利润率常先见顶（撞到目标毛利/经营利润率天花板就减速）；利润的拐点往往晚于利润率（要等营收也见平台）。
- ⚠️ **反面教训**：只写"利润率减速"会被误读成"利润要见顶"——**错**。必须同时给出绝对利润的方向。

**输出风格（本栏与其他栏不同，务必遵守）：**
- ✅ 正确："毛利率与营业利润率本季均出现**大幅单季跳升**，中间那一季的走平纯属季节性、非趋势中断；绝对利润的 QoQ 增量**一季比一季大，二阶导为正，尚未见拐点**；且 2028 年目标毛利率被自己上修，**asymptote 在上移，不是撞平台**。"
- ❌ 错误："GM 23.5→26.7→26.8→29.9%（QoQ +200→+320→+10→+320bp），OM 12.8→16.1→15.6→19.6%（+210→+330→−50→+400bp），营业利润 50.58→70.83→64.57→90.29（增量 +14.7→+20.2→−6.3→+25.7）……"——**这是把 dashboard 抄了一遍，不是速读**。
- **程度副词是必需品**：大幅 / 显著 / 温和 / 小幅 / 首次 / 创纪录 / 二阶导为正 / 减速上行 / 已见平台。
- **锚点数字最多保留 2–4 个**（通常是：营收和 EPS 相对指引区间的位置或 beat/miss 幅度、本季利润率水平及其台阶、长期目标利润率）。其余一律转成方向与程度。
- **GAAP 与 Non-GAAP 分开**：口径差额的**构成与趋势**比金额重要（是纯 SBC 还是含并购一次性？占比在收窄还是走阔？收窄是因为分子变小还是分母变大？）。GAAP 若有一次性大项要单独点明"不影响 Non-GAAP / 经营"。
- **一句话点出本季唯一实质恶化项**（如税率归一、汇兑、一次性费用），并说明它是永久性还是一次性。

### 【细分产业】—— ⭐ 抓"公司对产业的判断"，不是抓"公司自己的增长"

**这一栏最容易写偏成"分产品营收播报"。** 正确的对象是：**管理层对每个产品/方向所处的产业阶段、产业渗透进度、以及该环节供需关系的定性描述**。自家增长数字只作为佐证，不是主体。

**每条产品/方向要回答的三个问题：**

1. **产业进度到哪一步了？**——技术验证 / 首单商业化 / 早期渗透 / 加速替代 / 替代已完成、战线前移。⭐ **最有价值的是"阶段措辞的跨季变化"**：例如从"某某形态会长期主导"变成"某某替代已基本完成、下一个前沿是……"——这种措辞升级比任何数字都重要，必须单独高亮。
2. **产业供需是什么状态？**——供不应求 / 缺口幅度 / sold out / 可见度延伸到哪一年 / 供给正在增加。以及**瓶颈环节有没有迁移**（上季卡在 A，本季卡在 B）。
3. **这条线为什么能起量 / 起不来？**——产业侧的成立条件是什么（生态兼容性、可靠性顾虑是否消解、成本曲线、客户采用门槛）。**这个"为什么"比"涨了多少"更值钱**，因为它决定需求的可持续性。

**其他要点：**
- **从叙事到首单的商业化拐点**（"first commercial order"、"initial order"、"first-to-market"）——单独高亮，这是产业进度最硬的证据。
- ⚠️ **替代 vs 叠加要分清**：新形态若是替代老形态（不增加单位价值量），必须明说——否则读者会误以为是增量。
- **★不要把"自成一条投资主线"的环节压缩成一句**：像 scale-across、OCS、CPO/NPO、pump laser 这种独立可货币化的环节，**即使不是当季最大新闻也要独立成条**。**判断标准**：如果这个环节在「逻辑和叙事」里被列为一条护城河/成长曲线，那它在细分产业 + 订单里就必须有对应的独立覆盖。
- **整体产业供需的缺口要点破**：如果同业在大举扩产而管理层拒绝或无法评估行业供需平衡，这本身是本栏最重要的 ⚠️ 信号，必须写出来。
- 与光通信 / AI / 数据中心相关的产品多写两句，其余从简。

### 【订单】—— 抓"可见度"与"真实性"，逐条成长曲线都要落订单

- 总 backlog / RPO 规模、硬件vs服务/软件拆分、多少在未来 N 个月内交付、LTA 或长约覆盖到哪一年。
- **★每条主线的订单信号分别落一句**：sold out / 扩产倍数 / 市占 / LTA 结构（take-or-pay、几年期、pricing lever）/ 首个三位数季时点等，别只写一个总量就带过。
- "真实订单"信号：客户催着提前交货、把长约往前拉——比 backlog 数字更能说明需求硬度。
- ⚠️ **关键金额停止更新是重大信号**：某个被反复引用的合约/backlog 数字连续两季未更新，必须点出——尤其当管理层被分析师直接追问后确认"没有更新"时。
- ⚠️ **区分"产能口径"与"订单口径"**：管理层常同时给出产能倍数与合约金额，二者不可混用。"spoken for（有主）"≠"booked（已下单）"，必须原样保留这类限定词。

### 【客户】—— 抓"结构变化"

- hyperscaler 层：有无新增/份额腾挪、谁掉出 10%+。
- neocloud / neoscaler / 二线云：动能升级（"部分有 momentum" → "绝大多数拿下"这种跃迁要点出）。
- 新赢单、独家供应、送样→验证→量产的节点推进；build vs buy 客户从自供转外购的 crossover 时点。
- ⚠️ **消失的客户与消失的口径同样重要**：上季点名的客户/合作方本季集体缺席、或"X 家活跃客户"这类口径不再重申，必须列出——这是 ⚠️ 判断的常见来源。

### 【业绩节奏】—— ★全篇最重要的一栏，只写 delta

- 相比上一季电话会：什么**加速**（时间表提前、体量上修）、什么**推迟/下修**、什么**首次出现**（新产品线/新客户/新叙事）、供给最紧的环节有没有**迁移**、哪个口径**变了基准**。
- 用 🔼 / 🔽 / 🆕 / ➡️ / ⚠️ / 📌 逐条标注方向。
- 一句话点出本季相对上季"故事变了哪里"。若基本没变，就写"除 X 外无变化"——这本身也是信息。

### 【其他】—— 补上不入五维但关键的（不打判断标记）

- 供给约束具体到产品。
- 多年 TAM 及拆解（如管理层给了）。
- 产能/CapEx 节奏、定价机制、股本/一次性项、管理层战略措辞升级、长期财务模型有没有被自己跑赢/上修。
- 悬而未决的法律与商业事项（诉讼、纠纷、监管），以及是否已在报表中计提。

## 标签 tag 约定（`---{财季}---{tag}---`）

- `超预期` / `符合预期` / `不及预期`：以本季实际 vs 指引与一致预期为准。
- 可叠加节奏词：`超预期` 且连续 raise → 可写 `超预期·beat-raise`。
- 拿不准就用中性 `符合预期`，并在财务栏客观说明 beat/miss 的方向与程度让读者自判。
- ⚠️ **标题 tag 与六维判断标记是两件事**：一个季度完全可以是「超预期」但订单/客户维打 ⚠️——业绩好和信号干净不是一回事。

## 风格铁律

1. **语言见「约定」**；中文速读里关键英文原词/产品代号保留（Hyper-rail、EML、CW、pump laser、scale-across、multi-rail、1.6T、OCS、CPO、NPO、ELS、LPO/LRO 等不翻译）。
2. **数字的用法分栏不同**——
   - **财务栏**：少数锚点数字（2–4 个）+ 趋势 + 程度副词。**不列增幅序列、不搬 dashboard**。
   - **细分产业栏**：以产业阶段与供需的定性描述为主，数字作佐证。
   - **订单 / 客户 / 业绩节奏栏**：**尽量带数字**——"pump 4 倍扩产、~70–80% 市占、3 年 take-or-pay"而不是"订单强劲"。
3. **加粗关键判断词与拐点词**（不只是加粗数字），让人扫一眼就抓到结论。
4. **克制**：不写买卖建议、不判断"贵/便宜"、不外部臆测；忠实于 md，翻译不夸大（"cautiously optimistic"=审慎乐观，别写成"非常看好"）。
5. **业绩节奏那一栏永远聚焦 delta**，不要把本季静态描述再抄一遍。
6. **判断标记必须真判断**（见上文「判断标记」章节）——六维全 ✅️ 需要重新检查一遍。
