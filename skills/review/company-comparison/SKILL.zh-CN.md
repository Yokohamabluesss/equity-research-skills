# 同赛道公司对比（Company Comparison）

把用户已经做过的单公司研究（电话会日志、速读、估值表、会议纪要）横向拼成一份对比。**不重新做研究**，只基于已有材料整合；材料缺的地方明确标「笔记未覆盖 / 待核实」，不要用记忆补数字。

## 约定（固定不变）

- **语言**：用用户提问的语言。四个板块标题固定：`1. 业务方向和战略` / `2. 关键技术差异` / `3. 估值和财务` / `4. 其他重要的`（英文：`1. Business and strategy` / `2. Key technology differences` / `3. Valuation and financials` / `4. Other important points`）。「一句话定位」永远用英文。
- **材料位置**：每家公司 `{RESEARCH_ROOT}/{TICKER}/`（连接了用户电脑时用设备工具读取）。如果项目里也有同名副本，本地通常更新（例如估值速读可能只在本地）——按修改时间取最新。

## 1. 收集材料（先做，再写）

1. 列出每家文件夹，按修改时间排序，优先用最新的：
   - `{TICKER}_估值速读.md` / `{TICKER}_Valuation_Brief.md`：指引 / 假设 / 结论，PE、PEG、FCFF 反推、与一致预期差距
   - `{TICKER}_速读.md` / `{TICKER}_Digest.md`：护城河逻辑 + 最新一季要点
   - `{TICKER}_Earnings.md`：先 grep `^#` 看结构，读「速览 TL;DR」「业绩展望」「Product Summary Table」，不要全文读
   - 会议纪要（如 `0827 会议纪要.txt`）、展会/发布会 transcript（如 `ECOC2026.txt`），用 grep 抓技术关键词（CPO / NPO / OCS / ELS / VCSEL / 6-inch / 400G 等）
   - `{TICKER}_Valuation_Dashboard.xlsx`：读 `Conclusion`、`Assumptions`（市值、股本、现金、债务）、`Reverse DCF & Comps`
2. xlsx 如果 `data_only=True` 读出空值（公式没缓存），先用 LibreOffice 重算（`python scripts/xlsx_check.py 文件`）再读。
3. 用户说「基于 X 和 Y 这两个对话」时，先用 conversation_search 找；找不到就用上面的文件，并在开头说明数据来源。
4. 记下每家估值表的取价日期，两家不同日期要标出来。

## 2. 输出结构（对话内回复，Markdown 表格）

开头一句：说明数据来源与股价日期；如果临近财报，点出日期。

### 一句话定位（English）
每家一条英文 bullet，**粗体 ticker + 冒号 + 定位**。定位要抓商业模式本质（例如 LITE: "The ultimate upstream of optical communications"；COHR: vertically integrated from substrate to full optical solutions）。用户可能会改措辞，以用户的版本为准。

### 1. 业务方向和战略
表格行：营收规模与增速、最新季度、业务结构（分部占比）、核心战略、关键客户/战略投资方、订单可见度、管理层最看重的新方向。表后用一段话点出**战略上最大的分歧**，以及这个分歧对另一家意味着什么。

### 2. 关键技术差异
按技术大类逐行（赛道相关，光通信默认：EML / InP 产能与晶圆尺寸 / CPO / NPO / OCS / 光模块 / scale-across·DCI / 芯片间互连），列：A 的做法与节点、B 的做法与节点、谁领先/差异在哪。表后一段：哪家在路线之争里更中性、哪家押得更集中。
- 技术实现细节（如 OCS 用 MEMS 还是液晶）笔记里没写的，不要凭记忆写，标「未核实」或略过。

### 3. 估值和财务
统一口径表格行：股价/市值（基本股本与摊薄股本）、净现金/净负债、Non-GAAP 毛利率、经营利润率、FCF、季度资本开支、FY 当期/下期 PE、EPS 增速、PEG（两年 CAGR 口径 + 统一 S&P 3 年增速口径）、FCFF Base 每股（注明非目标价）及相对现价折溢价、反推现价隐含条件、自建 vs 一致预期。

表后 2–3 条判断，固定要算的：
- **营业利润绝对额对比**：用下一季指引中值算（营收 × 经营利润率），与市值比对比，说明市场多付/少付的是什么（增速斜率、利润率质量）。
- **同口径溢价是否一致**：FCFF Base 相对现价的折溢价、反推所需高速增长年数、统一口径 PEG。如果几乎一致，说明便宜的那家是「增速低」而不是「错杀」。
- **各自模型的风险点**：分歧来自营收斜率还是利润率；指引覆盖率、目标反解占比。

### 4. 其他重要的
从以下清单里挑实际有差异的写，不凑数：定价机制（长协锁价 vs 现货涨价弹性）、资本强度与资产负债表（CapEx、FCF、库存天数、杠杆）、地缘/FCC/美国产能、客户透明度与集中度、一次性 GAAP 项目与摊薄、股价位置（52 周涨幅）、**下一次财报各看什么**（逐家列 2–3 个验证点）。

结尾一行：可以把对比存成 `{RESEARCH_ROOT}/{A}_vs_{B}_对比.md`（英文 `{A}_vs_{B}_Comparison.md`），财报后更新。

## 3. 规则

- 所有表格用 Markdown table。
- 不给买卖建议、不给目标价；FCFF 每股值永远注明「非目标价」。
- 数字必须来自材料，口径不一致（财年不同、取价日不同、GAAP/Non-GAAP）要标注。
- 多于两家时，表格加列即可；「一句话定位」每家一条。
- 「最终上游」这类定位要准确：如果严格说还有更上游（如衬底），在回复末尾一句话提示可改为更精确的说法。
