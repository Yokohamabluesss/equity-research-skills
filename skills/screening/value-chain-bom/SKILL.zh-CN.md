# Value Chain BOM（产业链价值量拆分）

把一条产业链拆成 **「分层价值量占比 × 多场景 × 每层标的图谱」**，产出一份全公式联动的 xlsx。

用户拿到的东西应该能回答三个问题：**钱在哪一层？这个占比在什么条件下会变？每一层我能买谁？**

## 约定（固定不变）

- **语言**：用用户提问的语言。sheet 名按语言固定（见第四节）：中文 `1_价值量总表 … 7_来源`，英文 `1_Value Summary` / `2_Scenarios & BOM` / `3_True Variable` / `4_Company Map` / `5_Key Layer` / `6_Market Size Check` / `7_Sources`。
- **交付前检查**：`python scripts/check_bom_xlsx.py 文件.xlsx`——LibreOffice 重算、公式错误、以 `=` 开头的文字、未加引号的跨表引用、sheet 名与顺序、至少 3 个场景、占比是否为公式、来源页首行限制说明。所有 FAIL 必须修掉。

---

## 一、这个 skill 的核心主张

> **单一场景的价值量占比是有误导性的。**

同一条产业链，换一个隐藏参数，各层占比可能天差地别。所以本 skill **强制做多场景**，并且要求把那个"隐藏参数"显式找出来、做成可调输入。

配套的第二个主张：

> **价值量占比高 ≠ 值得买。供给结构才是。**

一个占 BOM 1% 的环节，如果供给是双寡头、不可被客户自研替代、不参与降价通缩，可能比占 70% 但充分竞争的环节更值得研究。表里必须把这个对比做出来。

---

## 二、工作流（六步，顺序不要改）

### Step 0：确认口径

先问清楚（或在开头明确声明）三件事：

1. **算什么、不算什么**。例：光通信 DCI 通常只看 optical connectivity，不含交换 ASIC 与路由器本体；固态电池通常只看电芯 BOM，不含 PACK 与 BMS。**口径不说清楚，占比数字没有意义。**
2. **单位是什么**。单条链路 / 单台设备 / 单 GWh / 单辆车 / 单机柜。全表统一。
3. **市场范围**。默认 A 股 + 美股，其他市场（港股/日股/台股/未上市）列为格局参照并标注。

### Step 1：先研究，别急着建表 ⚠️

**这一步花的时间应该占全程一半以上。** 没有事实就建模，出来的是一张精致的废纸。

要搜到的东西，按优先级：

1. **ASP 锚点**（最重要）——找一个能反推单价的公开数据组合：
   - `某品类年出货量 + 年收入` → ASP。这是最硬的反推方式
   - 大厂财报里的分产品收入 ÷ 出货量
   - 渠道价 / 官网报价（注意：渠道价含厂商溢价，大客户长约价可能低一半以上，要标注）
2. **各层的技术参数**——决定数量的物理量（速率、容量、损耗、能量密度、面积、层数……）
3. **拓扑/架构因子**——一个单元里到底装几个（双向？冗余？级联？分度？）。**这一层最容易算错**
4. **每层的市场规模**——用来做自上而下交叉验证
5. **每层的玩家与份额**——供给集中度是后面判断的关键

### Step 2：找出「真变量」⭐

这是本 skill 最有价值的一步。

**方法**：先按最直觉的方式算一遍占比，然后问自己——**如果这个数字和市面上流传的版本对不上，是哪个假设不同？**

那个不同的假设，往往就是真变量。

> **实例**：光通信 DCI 的价值量拆分，市面通行版本是「相干模块 65–80%、泵浦 1–4%」，而按满配算出来是「模块 91%、泵浦 0.6%」。两者都对——差别在**每根光纤点亮几个波（填充率）**。通行版本隐含 6–8 波，满配是 32 波。**填充率就是真变量，而不是大家以为的"距离"。**

找到后，把它做成 xlsx 里的**蓝色可调输入**，并单独做一页敏感性。

**常见的真变量类型**（供参考，不要生搬）：
- **填充率 / 利用率**：设备装了但没用满
- **拓扑因子**：双向、冗余、级联级数、节点度数
- **代际混合**：新旧规格同时在售，占比按混合比例变
- **一次性 vs 重复**：有些层是一次投入，有些层随用量线性增长

### Step 3：建 BOM 模型（至少 3 个场景）

场景怎么选？**沿着真变量的取值区间选三个点**，覆盖"保守 / 典型 / 极端"。

每层的金额一律写成：

```
该层金额 = 数量公式 × 单价
数量公式 = 场景参数的乘积（必须能一眼看懂物理含义）
```

**数量公式一定要写出物理含义的注释。** 例如「每纤对终端配 4 台放大器 = 2 个方向 ×（booster + preamp）」——这种拓扑因子漏掉一个，结果就差一倍。

### Step 4：自上而下交叉验证

用公开的市场规模反过来检查自下而上的模型是否离谱：

```
某层可寻址市场 ≈ 该层单价 × 全行业年数量
```

对不上就回去查假设。**对得上也要写下来**——这是模型可信度的重要背书。

同时留一个**自检位**：例如「某零件占整机 BOM 的比例」既是输入假设，又能被「零件单价 × 数量 ÷ 整机单价」反算出来。两者偏离过大，说明 ASP 假设内部不自洽，要在表里明确标出来而不是藏起来。

### Step 5：分层挂标的

**每一层后面必须跟公司。** 这是这张表区别于普通行业研究的地方。

主表里每层给「美股标的 / A股标的」两栏，另开一页做详细图谱：

| 公司 | Ticker | 市场 | 所属层级 | 该层具体产品 | 该层地位 | 阶段 | 证据 | 关键证据/备注 |

要点：
- **一家公司可以横跨多层**，在「所属层级」里写全（如「③泵浦 ＋ ②EDFA ＋ ⑤DGE ＋ ⑥WSS」），这本身就是重要信息
- **地位是按"在这一层"判断的，不是按公司整体**。一家光模块龙头在相干层可能只是二线
- **某层如果 A 股是空白，就明确写「❌ 无」**，不要含糊过去。空白本身是结论
- 上游材料/衬底类公司要注明**它跟随下游哪条线**，而不是笼统算作受益

### Step 6：出 xlsx 并校验

见第四节的固定结构和第五节的技术要点。**必须跑 `scripts/check_bom_xlsx.py`（内含 LibreOffice 重算）并确认零公式错误。**

## 三、证据分级与「同名不同物」检查（提醒，不强制）

产业链研究里最常见的翻车，是**把一个技术上完全不同的产品，当成了目标赛道的敞口**。这类错误往往由自媒体产业链梳理传播，而且带着很精确的数字（产能、良率、客户名单），看起来极其可信。

**建议给每家公司标一个证据等级：**

| 等级 | 含义 |
|---|---|
| ⭐⭐⭐ | 公司公告 / 年报正文 / 官方新闻稿 / 财报电话会 |
| ⭐⭐ | 官网产品页 / 展会官方发布 / 券商深度（可溯源） |
| ⭐ | 第三方梳理 / 自媒体，无法回溯到官方 |
| ❌ | 已证伪 |

**当某个说法带有下列特征时，值得回年报原文核对一遍：**

- 「国内唯一量产 XX」「全球唯三」「打破海外垄断」
- 附带很精确但无出处的数字（月产能 X 万颗、良率 X%、订单排到某年某季）
- 客户名单里都是知名大厂，但公司自己从未披露

**「同名不同物」高频陷阱（跨行业通用）：**

| 陷阱类型 | 例子 |
|---|---|
| 同材料不同等级 | 光学级铌酸锂晶圆 vs 射频 SAW 用钽酸锂——都是"锂"晶体，用途完全不同 |
| 同波长不同用途 | 980nm **通信级单模**泵浦（EDFA 用）vs 976nm **工业级多模**泵浦（光纤激光器用） |
| 同器件不同制式 | **相干** CDM 调制器（长距/DCI）vs **PAM-4** 调制器（数通/短距） |
| 同名词不同层 | 光模块里的"光源"（1310nm CW，被放大的信号）vs 放大器里的"泵浦"（980nm，提供能量） |
| 上游不区分下游 | 衬底/材料厂对下游两条线不做区分，量跟着**出货量大的那条**走，不是跟着**叙事热的那条**走 |

判断上游材料标的归属时，做一次**量级对比**：如果 A 应用年出货 20 万只、B 应用年出货 1200 万只，那上游材料厂本质上是 B 的标的，哪怕 A 的单价高 10 倍——因为**材料按片数/重量卖，跟下游单价无关**。

## 四、xlsx 固定结构（7 页）

页名前面带序号，方便排序。

### 1_价值量总表 ⭐ 主表

一张表回答全部问题。列结构：

| 层级 | 核心器件 | 场景A % | 场景B % | 场景C % | 参照区间 | 校验 | 美股标的 | A股标的 |

要求：
- **占比全部是公式**，引用 BOM 页，改假设自动重算
- **价值量最大的那一层要再切细**（子层缩进用 `　├` `　└`），因为公司完全不同。合计行记得扣除子项避免重复计数
- 表下方放**校验区**：如果用户或市面上有一个参照版本，逐条比对并给判定
- 再下方放**口径说明**：不计入本表的层是哪些、为什么、对应哪些公司

### 2_场景与BOM

- A 节：场景参数（蓝色可调）。每行带单位和依据说明
- B 节：单价假设（蓝色可调，黄底），每条带**低/中/高三档 + 置信度 + 依据**
- C 节：BOM 明细，三场景并列，每行带「核心器件」和「计算口径」
- D 节：辅助指标（数量、容量、单位价值量）
- E 节：如果主层要切细，在这里放内部拆分比例（带合计 100% 校验）

### 3_真变量敏感性 ⭐

沿真变量取 5 个点，显示各层占比如何漂移。

**必须同时显示"占比"和"绝对金额"两列**——最有价值的观察往往是「占比被稀释了但绝对金额没变」。

下方给一段"读法"文字，明确说明该盯哪个指标。

### 4_公司图谱

每家一行，字段见 Step 5。按层级分组，同层内按证据强度排。
已证伪的公司**保留在表里**并用红底标注，这样用户能看到"没漏处理"。

### 5_关键层专页

对最值得深挖的那一层（通常是"占比低但供给集中"的那层）单开一页：

- A 节：三场景下的数量、金额、占比、单位价值量
- B 节：**六维对比表**——该层 vs 价值量最大的那层，比较：供给集中度 / 能否被客户自研绕开 / 是否参与降价通缩 / 是否被真变量稀释 / 当前供需 / 价值量占比
- C 节：针对性的专题问答（用户在对话里问过的关键问题）
- D 节：一句话总结，含**天花板提示**（占比低意味着绝对收入体量的上限）

### 6_市场规模交叉验证

自上而下的规模数据，含推算行（公式）。下方写"读法"，特别要标注**第三方口径分歧**（很多细分市场不同报告差好几倍，通常是统计口径包不包某个应用的问题）。

### 7_来源

第一行必须是**首要限制说明**：哪些数字有公开出处、哪些是估算、这张表的价值在哪里（通常是"结构与相对关系"而非"绝对金额"）。

后面逐条列信源，注明来源类型。

## 五、构建技术要点（踩过的坑）

用 `openpyxl` 写，用 LibreOffice 重算。以下是必须避开的问题：

### 1. 文本单元格不能以 `=` 开头

说明文字写「= 波道数 × 数量 × 2」会被当成公式，重算后变 `#NAME?` 或 `#N/A`。
**用 `≡` 代替，或改写成「等于 …」。**

写完后扫一遍：

```python
for ws in wb:
    for row in ws.iter_rows():
        for c in row:
            if isinstance(c.value, str) and c.value.startswith("="):
                # 不含函数名和单元格引用的，就是被误当公式的文本
                ...
```

### 2. 跨表引用必须带前缀

`="C10/C20"` 在别的表里指向的是**本表**的 C10。必须写成：

```python
"='2_场景与BOM'!C10/'2_场景与BOM'!C20"
```

表名含空格或以数字开头时，单引号不能省。

### 3. 列的语义不要混

同一张假设页上，**场景列**（C=场景A、D=场景B、E=场景C）和**区间列**（C=中枢、D=低、E=高）如果并存，极易引错。
**建议：场景参数和单价假设分成两个区块，并在取值时显式注释取的是哪一列。**

### 4. 拓扑因子容易漏

数量公式写完后，手算一个场景验证。典型漏项：
- 双向（收发各一套）
- 两端（发送端 + 接收端）
- 级联（一台设备内部几级）
- 节点度数（网状拓扑 vs 点对点）

### 5. 重算方式

`scripts/check_bom_xlsx.py` 通过 LibreOffice 重算（无界面、独立配置目录、200 秒超时），并用重算后的文件替换原文件——交付的文件带缓存值，别人打开立刻能看到数字。

### 6. 格式约定

- 字体统一 Arial
- **蓝色 = 硬编码输入，黑色 = 公式，绿色 = 跨表引用**
- 关键假设用黄底，关键层用橙底，已证伪用红底，不计入项用灰底
- 金额 `$#,##0;($#,##0);-`，占比 `0.0%`（**存小数不存百分数**）
- 说明性长文本设 `wrap_text=True` 并给 `row_dimensions[r].height`

### 7. 输出位置与命名

存到用户的研究目录（`{RESEARCH_ROOT}/`），命名 `{赛道}_价值量拆分_标的图谱_{YYYYMMDD}.xlsx`（英文 `{field}_Value_Chain_BOM_{YYYYMMDD}.xlsx`）。
交付文件，**不要在对话里复述整张表**——给三到五条最反直觉的结论就够。

## 六、交付时说什么

对话里只讲这几件事，其余留给表格：

1. **最反直觉的一条**（通常是"某层占比比想象的低/高得多"）
2. **真变量是什么**，以及它一变结果怎么变
3. **如果用户给了参照模型，逐条校验的结果**——完全吻合就直说吻合，并指出它隐含的假设
4. **A 股 / 美股各自的空白层在哪**
5. **一句限制说明**：哪些数字没有公开出处

## 附：完整参照案例（光通信 Scale-Across）

第一次用这个 skill 时可以照着这个骨架套。

**口径**：单条链路 optical connectivity 设备 BOM，不含交换 ASIC / 路由器本体、不含光纤光缆本体。

**真变量**：① 每根光纤点亮的波道数（填充率）② 跨段数。距离本身不是真变量。

**三场景**：
- A 园区高带宽：30km、100 对光纤、满配 32 波、单跨、C 带
- B 城域 IPoDWDM：80km、100 对、典型 8 波、单跨、C 带
- C 长距：1,400km、12 对、C+L 满配 73 波、17 个 ILA 站点

**分层与占比结果**：

| 层 | 场景A | 场景B | 场景C |
|---|---|---|---|
| ① 相干可插拔模块（含 DSP/ITLA/调制器/TIA） | 91.0% | 71.6% | 49.3% |
| ② EDFA/拉曼整机（不含泵浦） | 2.7% | 8.6% | 23.4% |
| ③ **泵浦激光器** | **0.57%** | **1.79%** | **15.4%** |
| ④ Mux/Demux 无源 | 1.7% | 5.4% | 0.8% |
| ⑤ OCM/DGE/OTDR 监控 | 2.3% | 7.3% | 1.2% |
| ⑥ WSS/OCS 光交换 | 0% | 0% | 2.2% |
| ⑦ 线路系统机框 | 1.7% | 5.4% | 7.7% |

**ASP 锚点**：由「2026 年 800ZR/ZR+ 出货 >20 万只、收入 >10 亿美元」反推模块 ASP ≈ $5,000。其余层无公开 ASP，为区间估算。

**关键观察**：填充率从 4 波升到 32 波，模块占比 55.7%→91.0%、泵浦占比 2.79%→0.57%，但**泵浦绝对金额恒为 $200,000 一分未变**。跨段数才是泵浦占比的真正杠杆（0 跨 2.8% → 35 跨 21%）。

**为什么泵浦占比低却值得单开一页**：全球前五约 82% 份额的双寡头格局；无任何超大规模云自研 980nm 泵浦芯片；EDFA 按纤配不按波配所以不参与速率通缩；当前售罄并签 take-or-pay 长约。**四个条件同时成立的环节，全链只有这一个。**

**A 股空白层**：相干 DSP、ITLA、TIA/Driver、泵浦芯片——四层全空。唯一硬卡位是 TFLN 调制器那一层。
