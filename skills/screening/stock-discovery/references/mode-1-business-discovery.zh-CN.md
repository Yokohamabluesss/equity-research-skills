# Mode 1：业务挖掘 (Business Discovery)

## 目标

用户给一个**具体业务方向**（可大可小：大如"CPO"、"AI PCB"，小如"FAU"、"850nm VCSEL"、"硫化物固态电解质"），尽可能多地把做这个业务的上市公司挖出来。

**重点是覆盖广度 (coverage breadth)**——宁可多挖 3 家然后剔除，也不要漏掉一家有实质业务的公司。

## 表格列结构 (xlsx Schema)

固定 9 列，**顺序不要变**——脚本强制这个顺序。

| # | 列名 | 内容 | 必填 |
|---|---|---|---|
| 1 | 公司名 | 中文/英文公司名（双语都有就都给，逗号分隔） | ✓ |
| 2 | Ticker | 带交易所后缀的代码：`300308.SZ` / `LITE` / `9988.HK` | ✓ |
| 3 | 市场 | A 股 / 港股 / 美股 / ADR | ✓ |
| 4 | 相关产品 | 这家公司在该业务上的具体产品（产品名要细，不要写"光器件"，写"FAU 阵列"） | ✓ |
| 5 | 产业地位 | 头部 / 二线 / 新进入者 / ⚠️ 待确认 | ✓ |
| 6 | 产品阶段 | 量产 / 送样 / 研发 / 概念 | ✓ |
| 7 | 市场关注度 | 高 / 中 / 低 | ✓ |
| 8 | 涨幅滞后 | 🐢 是 / 空（不滞后或未查） | 选填 |
| 9 | 备注 | 关键客户、佐证来源链接、推测说明、双重上市等 | ✓ |

### 隐藏字段：子环节 (segment) — 强烈建议带上

业务挖掘几乎总是横跨多个产品子环节（光通信 = EML / CW / DFB / FAU / SiPh / 光模块；Low-CTE CCL 体系 = CCL 整板 / 球硅 / 玻纤布 / 树脂 / 铜箔）。在每个 row 上**额外加一个可选字段 `子环节`**，`build_xlsx.py` 会自动在 Summary 页渲染「子环节 × 产业地位」速览表——用户一眼看清整个赛道的玩家分布。

这个字段**不会进入 Companies 主表的 9 列**，**只用于 Summary 页**。

**约定**：

- 子环节命名要前后一致（"球形硅微粉" 和 "球硅" 是两个 bucket，不要混写）
- 一家公司放在它**最核心的**那个子环节里（不要为了"完整"把同 1 家公司复制到多个子环节，行还是按公司去重）
- 4-7 个子环节最佳，太多了 Summary 表会显得碎

## 排序规则

xlsx 里的行按以下优先级排序（由脚本完成）：

1. **产业地位**：头部 > 二线 > 新进入者 > 待确认
2. **产品阶段**：量产 > 送样 > 研发 > 概念
3. **市场关注度**：高 > 中 > 低（同档内放低关注度的在后面，方便用户对比"业务好但没人关注"的标的——这些是 alpha 来源）

## 搜索套路加强版

针对业务挖掘模式，下面这些搜索 query 在过去高效——优先尝试：

| 业务粒度 | 搜索 query 模板 |
|---|---|
| **大赛道**（CPO、AI PCB、固态电池） | `{业务} 产业链全景 / value chain map`、`{业务} 受益标的 券商`、`{业务} 国产替代` |
| **细分产品**（FAU、EML、硫化物电解质） | `{产品} 国内厂商 / domestic suppliers`、`{产品} 谁做`、`{产品} 招标 中标`、`{下游 KA} {产品} 供应商` |
| **新概念**（量子计算、CXL） | `{概念} 概念股 名单`、`{concept} pure play stocks`，但要小心**蹭热度**——核实公司是否真的有相关研发投入 |

## 常见陷阱 (Pitfalls)

1. **"概念股名单"陷阱**：百度/雪球的"XX 概念股"名单里常有蹭热度的公司——必须每家都到公司公告/年报核实。如果公司只在投资者互动平台说过一句"我们在关注/研究 XX"，但没有任何研发投入或产品计划披露，**只能标"概念"档**，不能写"研发"。
2. **混淆产品级别**：用户说"光通信"时，不要把所有挂"光通信"标签的都列上。一定要拆到具体产品（光模块？光器件？激光器芯片？）然后判断这家公司做哪一档——并在"相关产品"列写清楚。
3. **遗漏台股**：很多光通信、半导体的关键玩家在台股（联亚 LandMark、稳懋、华星光通、嘉晶等）。如果用户没明确排除，**台股的关键玩家也要列出来**，标注 "台股"，并提示"如不需要可剔除"。
4. **公司名同名问题**：`亨通` 在 A 股有两家（亨通光电 600487.SH vs 亨通股份），`长光` 也有多个——必须用 ticker 唯一确认。
