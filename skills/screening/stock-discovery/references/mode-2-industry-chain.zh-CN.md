# Mode 2：产业链梳理 (Industry Chain Mapping)

## 目标

用户给一条**产业链**（DCI / 800G 光模块 / 固态电池 / AI 服务器 / HBM / SiC 衬底 等），梳理上中下游每一环节的主玩家。

**重点是链条完整性 (chain completeness)**——尤其是上游环节（容易被忽略的设备、材料、关键器件）必须覆盖到。每个环节列 **1-2 家**主要玩家即可，**不要堆**。

## 表格列结构 (xlsx Schema)

固定 10 列，**顺序不要变**。

| # | 列名 | 内容 | 必填 |
|---|---|---|---|
| 1 | 环节层级 | 上游 / 中游 / 下游 | ✓ |
| 2 | 子环节 | 该环节的具体内容（如"上游-激光器芯片"、"中游-光模块封装"） | ✓ |
| 3 | 公司名 | 中英文公司名 | ✓ |
| 4 | Ticker | 带交易所后缀 | ✓ |
| 5 | 市场 | A 股 / 港股 / 美股 / ADR | ✓ |
| 6 | 该环节产品 | 公司在该子环节的具体产品 | ✓ |
| 7 | 产业地位 | 头部 / 二线 / ⚠️ 待确认 | ✓ |
| 8 | 产品阶段 | 量产 / 送样 / 研发 / 概念 | ✓ |
| 9 | 市场关注度 | 高 / 中 / 低 | ✓ |
| 10 | 备注 | 关键客户、市占率、双重上市等 | ✓ |

## 上中下游划分标准

| 层级 | 涵盖内容（典型） |
|---|---|
| **上游 (Upstream)** | 原材料 / 设备 / 关键芯片 / 关键器件——决定供给能力的环节 |
| **中游 (Midstream)** | 模组 / 封装 / 集成——把上游变成可用产品的环节 |
| **下游 (Downstream)** | 应用客户 / 整机厂 / 系统集成——决定需求拉动的环节 |

**判断原则**：跟着钱走 (follow the money)——上游卖给谁就是中游，中游卖给谁就是下游。如果同一家公司横跨多个环节（如三星横跨 HBM 上游和 NAND 下游），**在每个相关环节都列一行**，但备注里写明"同一公司"。

## 产业链常见模板（参考用，实际以行业为准）

### 800G 光模块产业链

```
上游：
  ├─ 激光器芯片：EML / CW (Lumentum LITE / 源杰科技 688498.SH)
  ├─ 调制器：硅光调制器 (Coherent COHR / 长光华芯 688048.SH)
  ├─ 探测器：APD / PIN PD (II-VI/Coherent / 三安光电 600703.SH)
  ├─ 光纤阵列：FAU (天孚通信 300394.SZ / 华工科技 000988.SZ)
  ├─ 透镜/隔离器：(蓝特光学 688127.SH)
  ├─ PCB：高频高速 PCB (沪电股份 002463.SZ)
  ├─ MCU/DSP：DSP芯片 (Marvell MRVL / Maxlinear MXL)

中游：
  ├─ 光模块封装：(中际旭创 300308.SZ / 新易盛 300502.SZ / Coherent COHR / 光迅科技 Accelink 002281.SZ)
  ├─ COB/CoWoS 工艺：(华工科技 000988.SZ)

下游：
  ├─ 交换机/路由器：(Arista ANET / Cisco CSCO / 锐捷 301165.SZ)
  ├─ AI 服务器/GPU：(NVIDIA NVDA / AMD / 浪潮 000977.SZ)
  └─ 云厂商：(亚马逊 / Google / Meta / 字节 / 阿里)
```

把这个模板作为**check-list**——做某条产业链时，对应每个层级问自己"这个环节有没有遗漏"。

## 搜索套路

1. **找一份现成的产业链全景图作为骨架**：
   - 中文：搜 `{产业链} 产业链 全景图`、`{产业链} 产业图谱`，**券商研报**里的产业链图最靠谱（中信、中金、华泰、申万等）
   - 英文：搜 `{industry} value chain map / supply chain diagram`

2. **逐环节搜每个环节的头部玩家**：
   - 上游环节最容易漏——一定要专门搜每个上游子环节（"激光器芯片 龙头"、"高速 PCB CCL 主要厂商"）
   - 上游设备/材料的玩家多在台股、日股、欧股，**别只看 A 股 + 美股**

3. **交叉验证（cross-check）**：
   - 把每个环节的玩家放到该环节的客户角度核验——"这家光模块厂的 EML 是从谁那买的？"——往往能发现遗漏的上游玩家

## 常见陷阱

1. **上游漏环节**：DCI、AI 服务器这种产业链，上游有几十个细分子环节（材料、设备、芯片、器件、连接器、电源、散热……）——容易漏的是"看起来不性感"的环节（CCL、连接器、电源管理芯片、散热器）。**梳理完之后必须自查**：物料清单上的每一类元件都对应到了一个或多个公司吗？
2. **把渠道商/经销商当玩家**：有些"概念股"其实只是产品的代理商或经销商——产业链梳理时**不要列代理商**，要列做产品的厂家。
3. **过度堆砌头部公司**：每个环节 1-2 家就够了。模式 2 不是"每家都列"，是"链条完整地说清楚谁是关键节点"。如果某个环节确实有 3 家鼎立（如光模块的中际旭创、新易盛、华工正源），可以列 3 家，但标注地位差异。
